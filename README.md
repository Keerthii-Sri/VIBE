# 🎵 VIBEVERSE – Music Streaming Platform

**Your Music, Your Mood!**

VIBEVERSE is a modern, responsive music streaming website designed to provide an immersive music-listening experience. Discover trending tracks, explore popular artists, browse albums, create personalized playlists, and enjoy music through an interactive music player.

---

## 🌟 Features

- 🎧 **Music Player** – Play, pause, skip, and control music playback.
- 🎤 **Popular Artists** – Discover popular artists and their music.
- 💿 **Albums Collection** – Explore albums with attractive cover images.
- 🎶 **Playlists** – Browse and create personalized playlists.
- 🔥 **Trending Tracks** – Discover popular and trending songs.
- 🕒 **Recently Played** – Access your recently played songs.
- ❤️ **Liked Songs** – Save your favorite tracks.
- 🔍 **Search Functionality** – Search for songs, artists, albums, and playlists.
- 🌙 **Dark & Light Mode** – Switch between different themes.
- 📱 **Responsive Design** – Compatible with desktop, tablet, and mobile devices.

## 🚀 Getting Started

Follow these steps to run the project locally.

**1. Clone the repository**

```bash
git clone https://github.com/YOUR-USERNAME/vibeverse-music-streaming.git
```

**2. Open the project folder**

```bash
cd vibeverse-music-streaming
```

**3. Run the website**

Open `index.html` in your browser or use the Live Server extension in Visual Studio Code.
